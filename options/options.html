Pilot Settings

Keys are stored locally in this browser profile only — nothing is sent anywhere except straight to each provider's own API when you run the agent.

Run behavior

Confirm every step Pilot pauses and shows you each click, type, or navigation before it happens.
Theme Applies to the side panel and this settings page.
Max steps per run Stops the agent automatically if a task runs long — a safety ceiling.
Pause between actions Milliseconds to wait after each action, so slow-loading pages catch up.
Fast mode Shorter network timeout + a smaller reply budget per step — snappier, best for simple pages. Complex forms may occasionally need an extra step.
Request timeout Give up on a slow reply and try the next key (or fail cleanly) after this many seconds.

Safety

Pilot always refuses to act on banking/financial, crypto-exchange, adult-content, and piracy sites — the same "hard block" approach browser agents like Claude in Chrome and Comet use, since those are the sites most worth protecting from a hidden prompt-injection instruction on the page. This built-in list isn't editable here.
